LUỒNG HOẠT ĐỘNG:

1. Backend Query (backend/src/routes/admin/products.routes.js)
   Endpoint: GET /admin/products/stats?year=2026
   
   SQL Query:
   - SELECT EXTRACT(YEAR/MONTH FROM orders.created_at) AS year/month
   - SELECT COALESCE(payments.method, 'COD') AS payment_method
   - SELECT SUM(orders.total_amount) AS revenue
   - FROM orders LEFT JOIN payments
   - WHERE status = 'COMPLETED'
   - GROUP BY year, month, payment_method
   
   Data Transformation:
   - Group by month
   - Tạo object: {month, COD: X, VNPAY: Y, STRIPE: Z, total: X+Y+Z}
   - Trả về sorted array by month

2. Frontend Render (src/app/admin/page.js)

   - Render BarChart (thay vì LineChart)

BACKEND LOGIC (backend/src/services/category.service.js):

getAllCategories():
  - Fetch tất cả categories
  - Loop qua mỗi category:
    
    a) Count Products:
       SELECT COUNT(*) FROM products 
       WHERE category_id = :category_id
       → product_count
    
    b) Count Sold (from COMPLETED orders):
       SELECT COALESCE(SUM(order_items.quantity), 0)
       FROM order_items oi
       JOIN products p ON oi.product_id = p.id
       JOIN orders o ON oi.order_id = o.id
       WHERE p.category_id = :category_id 
       AND o.status = 'COMPLETED'
       → sold_count
    
    c) Return enriched object:
       {...category, product_count, sold_count}

D. LUỒNG 4: HỆ THỐNG VIP MEMBER
================================================================================
Yêu CẦU: User chi tiêu >= 100,000 tự động lên VIP status

PHASE 1: DATABASE SCHEMA
File: backend/src/migrations/004-add-vip-fields.cjs

Thêm 2 cột vào users table:
- is_vip: BOOLEAN (default: false)
- total_spent: DECIMAL(15, 2) (default: 0)

Migration:
  - Kiểm tra column tồn tại rồi mới add
  - Hỗ trợ rollback bằng DROP column

PHASE 2: VIP STATUS CALCULATION SERVICE
File: backend/src/services/user.service.js

updateVipStatus(userId):
  Step 1: Fetch user
  Step 2: Query tất cả COMPLETED orders
  Step 3: Loop orders, sum total_amount
  Step 4: Calculate is_vip = (total >= 100000)
  Step 5: Update user: {total_spent, is_vip}
  Step 6: Log chi tiết: "[VIP Check] User X: Total = Y, Is VIP = Z"

PHASE 3: AUTO-UPDATE TRIGGERS
Có 4 điểm trigger updateVipStatus():

1. Admin Update Order Status:
   Endpoint: PATCH /admin/orders/{id}
   File: backend/src/routes/admin/orders.routes.js
   
   Khi admin change status → COMPLETED:
   - await order.update({status})
   - await userService.updateVipStatus(order.user_id)
   - Return success

2. MoMo Payment Webhook:
   Endpoint: POST /payment/momo/ipn
   File: backend/src/controllers/payment.controller.js
   
   Khi MoMo callback resultCode == 0:
   - await orderService.completeOrder(orderId)
   - await db.Payment.update({status: COMPLETED})
   - await userService.updateVipStatus(order.user_id)

3. VNPay Payment Webhook:
   Endpoint: POST /payment/vnpay/ipn
   
   Khi VNPay callback responseCode === "00":
   - await orderService.completeOrder(orderId)
   - await db.Payment.update({status: COMPLETED})
   - await userService.updateVipStatus(order.user_id)

4. Stripe Webhook:
   Endpoint: POST /payment/stripe/webhook (raw body)
   
   Khi event type "checkout.session.completed":
   - await orderService.completeOrder(orderId)
   - await db.Payment.update({status: COMPLETED})
   - await userService.updateVipStatus(order.user_id)

PHASE 4: FRONTEND - USER PROFILE
File: src/app/account/profile/page.js

Display VIP Badge:
  - Nếu user.is_vip === true:
    ⭐ VIP Member (amber badge)
  - Nếu false:
    Not VIP

Display Stats:
  Total Spent Box:
    💰 $X,XXX.XX
    "Spend $100,000+ to become VIP"
  
  VIP Status Box:
    ⭐ VIP / Not VIP
    "Thank you for being loyal" / "Almost there!"

PHASE 5: FRONTEND - ADMIN USERS MANAGEMENT
File: src/app/admin/users/page.js

Table Columns Thêm:
  - VIP: ⭐ VIP (nếu is_vip) hoặc "-"
  - Chi Tiêu: $X,XXX.XX (total_spent)

PHASE 6: ADMIN RECALCULATE ENDPOINTS
File: backend/src/routes/admin/users.routes.js

Endpoint 1: POST /admin/users/recalculate-vip/all
  - Fetch tất cả customers (role='customer')
  - Loop mỗi user, call updateVipStatus()
  - Response: {total_customers, updated, vip_count}
  - Dùng để: Fix data, resync sau migration

Endpoint 2: POST /admin/users/{id}/recalculate-vip
  - Fetch user by id
  - Call updateVipStatus(id)
  - Response: updated user data
  - Dùng để: Kiểm tra 1 user, debug

VII. BẢNG TÓMS TẮT ISSUES & SOLUTIONS
================================================================================

Issue 1: Admin Filter Not Working
  Cause: useEffect dependencies incomplete + backend không handle params
  Solution: Add all search params to dependencies + expand backend WHERE clause
  Status: ✅ FIXED

Issue 2: Revenue Chart Not Show Payment Methods
  Cause: Query không JOIN payments table
  Solution: LEFT JOIN payments, GROUP BY payment_method, format data properly
  Status: ✅ FIXED

Issue 3: Categories Don't Show Product Stats
  Cause: API chỉ return category info
  Solution: Add product_count + sold_count calculation in service
  Status: ✅ FIXED

Issue 4: User Not Become VIP Despite 100k+ Purchase
  Cause: total_spent column mismatch + not calculated from orders
  Solution: Query COMPLETED orders directly, sum amounts, compare >= 100000
  Status: ✅ FIXED

Issue 5: User Profile Show $0.00 Total Spent
  Cause: Auth endpoints don't return total_spent
  Solution: Calculate in /auth/me + /auth/profile, refresh after profile update
  Status: ✅ FIXED

Issue 6: Multiple VIP Updates on Same Order Complete
  Cause: Both payment webhook + admin update call updateVipStatus
  Solution: Idempotent design - safe to call multiple times
  Status: ✅ ACCEPTABLE (no data corruption)
